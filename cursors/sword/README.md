# Sword Cursor - Three Spin Blades

Version: **1.0.0**

Sword cursor with three alternating 360-degree click effects.

## Installation

Open [Sword-Cursor.user.js](Sword-Cursor.user.js), select Raw in GitHub, and confirm installation in Tampermonkey. Alternatively paste the full file into a new userscript and save. Disable older duplicate installations.

## Scope and permissions

Runs on ordinary HTTP and HTTPS pages where your browser permits userscripts. Browser settings pages and some restricted pages are not supported.

Requested userscript grants: `GM_getResourceURL`, `GM_registerMenuCommand`.

This script depends on externally hosted artwork. Those hosts may change or become unavailable. Original resource URLs and credits are preserved.
