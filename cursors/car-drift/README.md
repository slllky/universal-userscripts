# Car Drift Cursor

Version: **1.0.1**

Five car-inspired cursors, click-to-drift animation, and colorful neon or flame trails.

## Installation

Open [Car-Drift-Cursor.user.js](Car-Drift-Cursor.user.js), select Raw in GitHub, and confirm installation in Tampermonkey. Alternatively paste the full file into a new userscript and save. Disable older duplicate installations.

## Scope and permissions

Runs on ordinary HTTP and HTTPS pages where your browser permits userscripts. Browser settings pages and some restricted pages are not supported.

Requested userscript grants: `GM_getValue`, `GM_setValue`, `GM_registerMenuCommand`.
