# Bottom Patrol artwork

Each folder contains a transparent sprite sheet and a frame map. Sheets use 128 × 128 cells and the foot anchor (64, 116). Each map lists the native facing, ordered animation frames and the visible bounds of every cell. The painter uses those bounds for the hero’s clickable silhouette rectangle and the anchor for mirroring.

Rengoku is Kyojuro Rengoku from *Demon Slayer: Kimetsu no Yaiba*. The 2.0.0 hero sheets are newly illustrated fan sprites. The original 1.1.0 userscript credited Soulfire / SoulfireSprites for its Rengoku sheet. The returning Pink Demon uses the earlier sheet credited to id Software / Falcon Delta. Lantern Eye, Furnace Brute and Dusk Stalker have replacement art for the three previous CraftPix encounter slots. Silk Moth, Temple Bell, Foxfire and Basalt Oni are new fantasy opponents.

The public [art review folder](https://github.com/slllky/tampermonkey-art/tree/main/review/rengoku) contains the individual sheets. The original character designs and third-party art remain the property of their respective owners.
