# Jake — Stretch Walker

Version: **2.0.1**

Self-contained Jake: walks, stretches toward the cursor, and hops back down.

## Installation

Open [Jake-Stretch-Walker.user.js](Jake-Stretch-Walker.user.js), select Raw in GitHub, and confirm installation in Tampermonkey. Alternatively paste the full file into a new userscript and save. Disable older duplicate installations.

## Scope and permissions

Runs on ordinary HTTP and HTTPS pages where your browser permits userscripts. Browser settings pages and some restricted pages are not supported.

Requested userscript grants: `GM_getValue`, `GM_setValue`, `GM_registerMenuCommand`.
