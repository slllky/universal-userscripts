# Changelog

## 1.2.0 — The Storybook Edition

- Replaced geometric models with illustrated Cloudfox, Moonbun, and Dewdrop forms, each with awake and contented expressions.
- Added separate pigment recoloring for coats, rosy accents, and irises while retaining painted shading.
- Rebuilt the interface as a fieldbook with parchment pages, ribbon tabs, fabric swatches, illustrated accessories, and keepsake stamps.
- Added an illustrated conservatory with three lighting treatments.
- Added temporary wardrobe try-ons, appearance undo, owned-item outfit surprises, and editable outfit names.
- Updated animation for the painted companions and attached accessories.
- Embedded all artwork, kept HTTP/HTTPS matching universal, and preserved existing save identity and progress.

## 1.0.1

- Removed every userscript metadata exclusion and the runtime domain block. RIFT now matches all HTTP and HTTPS webpages, subject to the browser’s normal extension restrictions.
- Kept the per-site companion toggle under the user’s control.
- Preserved the userscript namespace and existing save format.

## 1.0.0

- First playable Cozy Companion Edition with three forms, temperaments, layered customization, care interactions, a sanctuary, gardening, expeditions, rift gameplay, local saves, and an offline preview.
