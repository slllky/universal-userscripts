# RIFT storybook artwork

- `familiars.webp`: Cloudfox, Moonbun, and Dewdrop in awake and contented poses, arranged in a three-column/two-row transparent atlas.
- `conservatory.webp`: the moonlit botanical sanctuary background.

Both illustrations were generated for RIFT with OpenAI's image-generation tool on November 17, 2026. The PNG outputs were converted to WebP for distribution. The browser applies SVG pigment filters, viewport crops, clothing layers, and animation; it does not fetch external artwork.

Creature crop windows deliberately differ in width: the axolotl's wide gills extend beyond a strict third of the atlas. Runtime and rendering tests use these production crop definitions.

Accessory illustrations, food icons, furnishings, interface styling, and animation/compositing code are included in the source. No third-party character artwork is used in this RIFT asset set. This note does not assert a blanket license for other scripts in the repository.
