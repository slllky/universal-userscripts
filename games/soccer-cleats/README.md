# Soccer Ball & Cleat Cursor

Version: **1.1.0**

A gently rolling soccer ball, cleat cursor, and directional kicks on any ordinary webpage.

## Installation

Open [Soccer-Cleats.user.js](Soccer-Cleats.user.js), select Raw in GitHub, and confirm installation in Tampermonkey. Alternatively paste the full file into a new userscript and save. Disable older duplicate installations.

## Scope and permissions

Runs on ordinary HTTP and HTTPS pages where your browser permits userscripts. Browser settings pages and some restricted pages are not supported.

Requested userscript grants: `GM_registerMenuCommand`, `GM_getValue`, `GM_setValue`.
