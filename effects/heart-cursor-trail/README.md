# Tiny Neon Heart Cursor Trail

Version: **1.0.1**

Tiny neon pink hearts follow your cursor; older hearts fade after ten.

## Installation

Open [Heart-Cursor-Trail.user.js](Heart-Cursor-Trail.user.js), select Raw in GitHub, and confirm installation in Tampermonkey. Alternatively paste the full file into a new userscript and save. Disable older duplicate installations.

## Scope and permissions

Runs on ordinary HTTP and HTTPS pages where your browser permits userscripts. Browser settings pages and some restricted pages are not supported.

Requested userscript grants: `none`.
